## Can I edit this repository?

Yes. This is your website and your repository: you are free to change, add or delete anything. But Website Builder manages most files here, so keep the following in mind.

- **Publishing again from Website Builder overwrites your changes.** Each time you publish, the tool rebuilds the HTML pages, `css/`, `js/`, `images/`, `fonts/` and `sitemap.xml` from the project in the tool. Changes you make directly in this repository are not copied back into Website Builder.
- **Files you add yourself are removed on the next publish.** Only this README, `CNAME` and the `.github/` folder are left alone.
- **Do not change or delete the `.webdesign/` folder.** It contains your project, encrypted with your password. Website Builder needs it to open this site again from GitHub. If it is missing or changed, the tool can no longer load or update this site.
- **Changing the default branch, renaming the repository or changing the GitHub Pages settings** can stop publishing from Website Builder from working.

Prefer to edit the code by hand from now on? That is fine. Just stop publishing from Website Builder, so your changes are not overwritten.

## About this README

Website Builder only adds this file when the repository has no README yet. You can edit or replace it, and it will not be overwritten.
